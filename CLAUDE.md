# ORION — Claude Code Instructions

Read docs/ORION_MASTER_SPEC.md for the complete product vision,
acceptance criteria, and execution strategy.

Read docs/PROJECT_CONTEXT.md for project history.

The repository is the source of truth for implementation status.

Before major implementation:
- Audit the current codebase.
- Compare it against the master specification.
- Produce a dependency-aware execution roadmap.
- Wait for approval.

During implementation:
- Preserve existing functionality and data.
- Work through verified milestones.
- Run tests and report actual results.
- Never fabricate completion.
- Require approval for destructive operations,
  commits, pushes, and deployment.

Build, test and style conventions: see AGENTS.md.
